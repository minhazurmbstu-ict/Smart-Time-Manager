# Smart-Time-Manager
A modular console-based digital stopwatch and timer system developed using C programming language.


📌 Project Overview

Smart Time Manager is a lightweight, console-based application designed to help users manage time efficiently. It combines four essential time management utilities into a single application.

✨ Key Features

- Stopwatch: Real-time stopwatch with Pause, Resume, and Stop functionality.
- Count-up Timer: Tracks elapsed time.
- Count-down Timer: Tracks remaining time based on a target duration.
- Alarm / Time Reminder: Allows users to set an alarm for a specific time.
- Periodic Reminder: Provides recurring reminders at fixed time intervals.

🛠️ Technologies Used

- C Programming Language
- Windows API
- conio.h
- time.h
- Code::Blocks / Visual Studio

📂 Project Structure

- "main.c" – Main program and menu management.
- "timer.c" – Timer and stopwatch function implementations.
- "timer.h" – Function declarations and header definitions.

🎯 Project Objectives

- Develop a modular and user-friendly time management application.
- Implement multiple timer and reminder functionalities.
- Ensure accurate real-time time tracking.
- Practice modular programming in C.
